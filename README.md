# Linux Basic Training

An interactive guide for absolute beginners to start learning Linux.

Single self-contained HTML file. No frameworks, dependencies or tracking.

## What's inside

- Distro explorer with 10 of the most common Linux distributions
- Type-it-yourself command practice across 7 categories
- Full reference guide covering everything from permissions to networking
- 20-question knowledge quiz with explanations
- Drag and drop matching challenges
- Tips and tricks section

## Live

[https://znuze.github.io/Linux-basic-training](https://znuze.github.io/Linux-basic-training)

## Usage

Download the HTML file and open it in any browser. Or just visit the link above.
